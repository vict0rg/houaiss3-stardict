# Contributing

Contributions are welcome under the following strict repository policy.

## Proprietary Content Is Prohibited

Do not submit:

- dictionary source files;
- decoded dictionary files;
- dictionary entries or definitions;
- screenshots from proprietary dictionary software;
- extracted images;
- generated dictionary databases;
- test data derived from proprietary lexical content;
- archives containing any of the above.

All test material must be entirely synthetic.

## Technical Documentation

Documentation may describe abstract file organization, record types, parsing
logic, indexing concepts, byte transformations, and interoperability behavior.

Documentation must not reproduce proprietary lexical content.

## Language

Project documentation, source comments, docstrings, issue templates, and
user-facing program messages should use American English.
